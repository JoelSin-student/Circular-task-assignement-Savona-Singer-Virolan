## Aim and files
This repository is a workspace where the students can upload, actualize and discuss about the parts of code they are in charge of for the circular task assignment (see ```circular-task-assignment.html```). 

Folders:\
    - ```data```: data to work on\
    - ```notebooks```: pieces of code\
    - ```students_results```: students' own results when performing the task

Files:\
    - ```main```: single notebook with all code\
    - ```circular-task-assignment.html```: assignment document
\
## Teamwork organization
### Organization
We divided the initial recomputing work in three (see below) corresponding to three branches with our names and three different notebooks in the ```notebooks``` folder. We set different roles to handle the rest of the assignment when we finished our branches. The following steps were:
- integrate the pieces of code in the ``main`` notebook;
- clean the integrated code;
- work on last details to copy the output format of the assignment;
- apply the code on students' results (see homonym folder).

During the first part (code division), we mainly interacted in a WhatsApp group, showing screenshots and discussing there when we faced issues. For the integration part, we reviewed ourselves with pull requests, merging into main only when the two others approved the changes.
